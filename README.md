# Collection of data strutures
This repo contains a bunch of data structures that I have recreated

## Running
Build the project and compile
```
make cmake
```

Run main
```
./build/main_app
```

Run vector tests
```
./build/vector/vector_tests
```
Run ring-buffer tests
```
./build/ring-buffer/ringbuffer_tests
```
